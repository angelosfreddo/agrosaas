RESUMO DA ENTREGA (CAPITULOS 3, 4, 5 E 6):
1. Problema do Agronegocio: Monitoramento, calculo economico (ATR) e diagnostico
   de causa-raiz para reducao das perdas na colheita mecanizada de cana-de-acucar.
2. Subalgoritmos (Cap. 3): Funcoes e procedimentos modulares com passagem de
   parametros (calculos.py, validacao.py, arquivos.py, repositorio.py, banco_oracle.py).
3. Estruturas de Dados (Cap. 4): Listas, Tuplas, Dicionarios e Tabela de Memoria.
4. Manipulacao de Arquivos (Cap. 5): Leitura/escrita JSON (parametros, modo offline,
   importacao/exportacao em lote) e arquivos Texto .TXT (laudos tecnicos e logs).
5. Banco de Dados Oracle (Cap. 6): Integracao via oracledb com bind variables,
   DDL automatizado e sincronizacao Offline-First (Upsert/Merge).
